# File Hosting & Download Guide (Transfer.it, Gofile, Pixeldrain)

คู่มือและแหล่งรวมข้อมูลบริการฝากไฟล์ยอดนิยม พร้อมตัวอย่างการใช้งานร่วมกับโปรแกรมดาวน์โหลดความเร็วสูง **aria2c**

---

## 📂 รายชื่อผู้ให้บริการฝากไฟล์

### 1. Pixeldrain (`pixeldrain.com`)
* **จุดเด่น:** โหลดไว ไม่ค่อยจำกัดสปีด เหมาะสำหรับไฟล์ขนาดเล็กถึงปานกลาง ลิงก์ตรงใช้งานง่าย
* **การใช้งานร่วมกับ aria2c:**
  ```powershell
  aria2c -x16 -s16 "[https://pixeldrain.com/api/file/FILE_ID](https://pixeldrain.com/api/file/FILE_ID)"

```

### 2. Gofile (`gofile.io`)

* **จุดเด่น:** รองรับไฟล์ขนาดใหญ่ อัปโหลดง่าย แต่มีเงื่อนไขเรื่องระยะเวลาเก็บรักษาและขีดจำกัดการดาวน์โหลดหากไม่มีการเคลื่อนไหว
* **การใช้งานร่วมกับ aria2c:** (แนะนำให้ใช้ลิงก์ดาวน์โหลดตรงจากตัวเว็บ Gofile)
```powershell
aria2c -x16 -s16 "[https://storeX.gofile.io/download/web/FILE_ID/filename.zip](https://storeX.gofile.io/download/web/FILE_ID/filename.zip)"

```



### 3. Transfer.it

* **จุดเด่น:** บริการส่งและแชร์ไฟล์ขนาดใหญ่ผ่านลิงก์ชั่วคราว สะดวก รวดเร็ว ไม่ซับซ้อน

---

## 🚀 ตัวอย่างสคริปต์ดาวน์โหลดด่วนด้วย aria2c (PowerShell)

หากต้องการดึงไฟล์จากลิงก์ฝากไฟล์เหล่านี้แบบเต็มสปีด (แบ่ง 16 ส่วน) สามารถใช้คำสั่ง PowerShell ด้านล่างนี้ได้ครับ:

```powershell
$FileUrl = "ใส่_URL_ดาวน์โหลด_ตรงนี้"
$OutFolder = "D:\Downloads"

aria2c -x16 -s16 -k1M --file-allocation=none -d $OutFolder $FileUrl

```

---

## ⚙️ สรุปพารามิเตอร์คำสั่งที่จำเป็น

| Option | ความหมาย |
| --- | --- |
| `-x16` | กำหนดการเชื่อมต่อสูงสุด 16 Connections ต่อเซิร์ฟเวอร์ |
| `-s16` | แบ่งไฟล์ออกเป็น 16 ส่วนเพื่อโหลดพร้อมกัน |
| `-d` | ระบุโฟลเดอร์ปลายทางสำหรับเซฟไฟล์ |
| `--file-allocation=none` | ข้ามการจองพื้นที่ดิสก์ล่วงหน้า ช่วยให้เริ่มดาวน์โหลดได้ทันที |
